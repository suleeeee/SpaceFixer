# SpaceFixer

一个用于检查并修复 Figma 文本空格与中英文排版规范的本地插件。

正式 Plugin ID：`1648025602357999016`

---

## 功能特性

- **中英文空格补充**：默认开启 `补充缺失空格`，规范中文与英文或普通数字之间缺少的半角空格。
- **角标智能保护**：默认开启 `排除角标`，Unicode 上下标与数字角标默认不参与缺失空格检查，避免排版冲突。
- **灵活扫描范围**：支持选中图层、当前页面或整个文件扫描。
- **跳过隐藏内容**：默认开启 `跳过隐藏图层`，文本自身或任一父级图层被隐藏时不参与检查。
- **可选多余空格清理**：支持独立开启行首尾空格删除、中文间非预期空格删除、中文标点旁空格删除、连续多余空格压缩为 1 个等细粒度规则。
- **专有名词保护（全员共享）**：
  - 保护品牌词与专有名词（如 `ChatGPT`、`iPhone`、`蓝心小V`、`iQOO 智能双面夹5 Pro`）内部格式不被拆分或误改；
  - 自动随当前 Figma 文件保存（`SharedPluginData`），同一文件中所有有编辑权限的协作成员免配置直接共用；
  - 检查结果列表中支持一键「忽略」快速加入专有名词保护库。
- **安全预览与定位**：
  - 单条结果点击 `定位` 使用 Figma 原生临时文本选区高亮，不污染任何设计图层与画板；
  - 单条即时修复；全部修复前提供汇总预览弹窗（图层数、缺失空格、多余空格及专有名词统计）。
- **极简轻量 UI**：
  - 初始 `420 × 367px` 紧凑尺寸，检测到问题或展开面板时弹性扩展；
  - 精致星芒空状态引导与暗色/浅色自适应外观；
  - 弹窗支持全局 `Escape` 快捷键与遮罩点击关闭。

---

## 导入与使用方式

1. 打开 Figma。
2. 进入 `Plugins > Development > Import plugin from manifest...`。
3. 选择本目录下的 `manifest.json`。
4. 运行 `SpaceFixer`。

换电脑或与团队协作时，专有名词保护随 Figma 文件自动漫游，打开文件即可共用。

## 检查规则参考

### 1. 补充缺失空格
- `中文A` -> `中文 A`
- `A中文` -> `A 中文`
- `中文1` -> `中文 1`
- `1中文` -> `1 中文`

### 2. 清理多余空格（可选开启）
- 每行开头和结尾的多余空格会被删除。
- `中文  中文` -> `中文中文`，中文字符之间多余空格会被清除。
- `12 34` 默认保持不变；`12  34` 默认压缩为 `12 34`；开启谨慎删除后修复为 `1234`。
- `中文  English` -> `中文 English`，中英/数字间超过 1 个空格时压缩为 1 个。
- `中文  ，说明` -> `中文，说明`，中文与标点符号间的空格会被删除。
- `佩戴 ¹` -> `佩戴¹`、`Pro ¹` -> `Pro¹`，角标左右的多余空格会被删除。
- `Hello  World` -> `Hello World`，英文词与数字间多个空格压缩为 1 个。
- 手动换行与回车会被完整保留，不影响分段排版。

## 文件结构

- `manifest.json`: Figma 插件配置。
- `code.js`: 插件沙盒线程，负责图层扫描、文案修复、专有名词数据保存。
- `ui.html`: 插件前端界面，包含交互逻辑与样式。
